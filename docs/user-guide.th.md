# คู่มือการใช้งานสำหรับเจ้าหน้าที่

**ระบบจองห้องประชุม สำนักงานเขตบางรัก** — ห้องประชุมเล็ก ชั้น 2 และห้องประชุมใหญ่ ชั้น 4

ใช้ได้ทั้งคอมพิวเตอร์ แท็บเล็ต และมือถือ

## 1. เปิดระบบ

เปิดเบราว์เซอร์ (Chrome, Edge หรือ Safari) แล้วพิมพ์ที่อยู่ของระบบ หรือสแกน QR Code ที่ติดไว้ในสำนักงาน

| รายการ                               | ของสำนักงาน (ฝ่าย IT กรอก)           |
| ------------------------------------ | ------------------------------------ |
| ที่อยู่ระบบ                          | \***\*\*\*\*\***\_\_\***\*\*\*\*\*** |
| ผู้ดูแลห้องประชุม / เบอร์ติดต่อภายใน | \***\*\*\*\*\***\_\_\***\*\*\*\*\*** |

> ถ้าระบบติดตั้งไว้ในสำนักงาน (ไม่ได้อยู่บนคลาวด์) ต้องเชื่อม **Wi-Fi หรือ LAN ของสำนักงาน** ก่อนจึงจะเปิดได้

เมนูหลักอยู่แถบบนสุดของทุกหน้า: **หน้าแรก · ปฏิทินห้อง · จองห้อง · การจองของฉัน**

## 2. หน้าแรก: ดูสถานะห้อง

![หน้าแรก](images/u-home.jpg)

- แถบประกาศด้านบนคือข้อความจากผู้ดูแล (กด × เพื่อซ่อน)
- กล่องตัวเลขบอกเวลาปัจจุบัน จำนวนการประชุมวันนี้ และจำนวนห้องที่ว่างขณะนี้
- กดปุ่ม **จองห้องประชุม** เพื่อเริ่มจอง หรือ **ดูตารางห้อง** เพื่อเปิดปฏิทิน

เลื่อนลงจะเห็นการ์ดของแต่ละห้อง

![สถานะห้องประชุม](images/u-home-rooms.jpg)

| สถานะบนการ์ด        | ความหมาย                              |
| ------------------- | ------------------------------------- |
| **ว่าง**            | ไม่มีการประชุมในขณะนี้                |
| **ไม่ว่าง**         | มีการประชุมอยู่ พร้อมบอกเวลาที่จะว่าง |
| **ใกล้เริ่มประชุม** | มีการประชุมจะเริ่มในไม่ช้า            |

แถบเวลาใต้การ์ดแสดงช่วงที่ถูกจองของวันนี้ (เส้นสีแดงคือเวลาปัจจุบัน)
ใต้แถบเวลามีรายการอุปกรณ์ที่มีในห้อง และปุ่ม **จองห้องนี้** / **ดูตาราง**

ข้อความ “**ยืนยันทันที**” ใต้ชื่อห้อง หมายถึงจองแล้วได้ห้องเลย ถ้าเป็น “**รอผู้ดูแลอนุมัติ**” การจองจะรอผู้ดูแลอนุมัติก่อน

ข้อมูลทุกหน้าจออัปเดตเองทันทีเมื่อมีคนจองหรือยกเลิก ไม่ต้องกดรีเฟรช

## 3. ดูตารางห้อง (ปฏิทิน)

![ปฏิทินรายสัปดาห์](images/u-calendar.jpg)

- เลือกมุมมอง **รายวัน / รายสัปดาห์ / รายเดือน** ที่มุมขวาบน
- ปุ่ม **‹ วันนี้ ›** ใช้เลื่อนวัน หรือกดที่ชื่อวันที่เพื่อเลือกวันจากปฏิทิน
- กรองเฉพาะห้องด้วยปุ่ม **ทุกห้อง / ห้องประชุมเล็ก / ห้องประชุมใหญ่**
- สีของรายการ: ทึบ = **อนุมัติแล้ว**, ลายเส้น = **รออนุมัติ**, ลายเทา = **ปิดใช้ห้อง** (ผู้ดูแลกันห้องไว้)
- **กดช่องว่าง** ในตารางเพื่อจองช่วงเวลานั้นทันที
- กดรายการที่มีอยู่เพื่อดูรายละเอียด
- บนมือถือ ปัดซ้าย/ขวาเพื่อเปลี่ยนวัน

## 4. จองห้อง 3 ขั้นตอน

กด **จองห้อง** ที่เมนูบน (หรือ **จองห้องนี้** บนการ์ดห้อง) กล่องสรุปด้านขวาจะแสดงสิ่งที่เลือกไว้ตลอดเวลา

### ขั้นที่ 1 — ห้องและเวลา

![ขั้นที่ 1 เลือกห้องและเวลา](images/u-book-1.jpg)

1. **เลือกห้องประชุม**
2. **เลือกวันที่** — วันที่ขีดฆ่าคือวันที่จองไม่ได้ (วันหยุด เสาร์–อาทิตย์ หรือเกินช่วงที่เปิดให้จองล่วงหน้า)
3. **เลือกช่วงเวลา**
   - แตะ **ช่องเวลาเริ่ม** แล้วแตะ **ช่องเวลาสุดท้าย** ที่ต้องการ
   - หรือแตะเวลาเริ่มแล้วกดปุ่มระยะเวลา เช่น **1 ชั่วโมง**, **2 ชั่วโมง**
   - หรือกด **ช่วงเช้า / ช่วงบ่าย / ทั้งวัน**
   - ช่องลายขีดคือเวลาที่ไม่ว่าง แตะช่องอื่นเพื่อเริ่มเลือกใหม่

กด **ถัดไป**

### ขั้นที่ 2 — รายละเอียด

![ขั้นที่ 2 กรอกรายละเอียด](images/u-book-2.jpg)

| ช่อง                  | หมายเหตุ                                                     |
| --------------------- | ------------------------------------------------------------ |
| หัวข้อการประชุม \*    | เช่น “ประชุมติดตามงานประจำเดือน”                             |
| ชื่อ–นามสกุลผู้จอง \* |                                                              |
| หน่วยงาน \*           | เลือกจากรายการ                                               |
| เบอร์โทรติดต่อ \*     | ใช้ค้นหาการจองจากเครื่องอื่น และให้ผู้ดูแลติดต่อกลับ         |
| อีเมล                 | ไม่บังคับ (เว้นแต่สำนักงานกำหนด)                             |
| จำนวนผู้เข้าร่วม \*   | ใช้ปุ่ม − / + แถบสีแสดงเทียบกับความจุห้อง                    |
| อุปกรณ์ที่ต้องการ     | แตะเพื่อเลือก รายการที่มีป้าย “มีในห้อง” คืออุปกรณ์ประจำห้อง |
| บริการเสริม           | เช่น น้ำดื่ม กาแฟ อาหารว่าง                                  |
| หมายเหตุ              | ข้อความถึงผู้ดูแลห้อง                                        |

\* = ต้องกรอก

**จองซ้ำ:** เลือก **ทุกสัปดาห์** หรือ **ทุกวันทำการ** แล้วกำหนดจำนวนครั้ง ระบบจะตรวจห้องว่างให้ทุกวันล่วงหน้า
วันที่ว่างจะมีเครื่องหมายถูก ถ้ามีบางวันไม่ว่าง ระบบจะถามว่าจะจองเฉพาะวันที่ว่างหรือไม่

ตัวเลือกท้ายฟอร์ม:

- **จดจำชื่อ หน่วยงาน และเบอร์โทรไว้ในอุปกรณ์นี้** — ครั้งหน้าไม่ต้องกรอกซ้ำ (ใช้กับเครื่องส่วนตัวเท่านั้น)
- **นี่เป็นอุปกรณ์ส่วนกลาง** — ใช้เมื่อจองจากเครื่องที่คนอื่นใช้ร่วม ระบบจะไม่เก็บการจองไว้ในเครื่องนั้น
  ให้จดรหัสการจองไว้ แล้วค้นหาจากเครื่องของคุณภายหลัง

กด **ถัดไป**

### ขั้นที่ 3 — ตรวจสอบและยืนยัน

![ขั้นที่ 3 ตรวจสอบและยืนยัน](images/u-book-3.jpg)

ตรวจข้อมูลอีกครั้ง อ่านระเบียบการใช้ห้องประชุม แล้วติ๊ก **ข้าพเจ้าได้อ่านและยินยอมปฏิบัติตามระเบียบการใช้ห้องประชุม**
จากนั้นกด **ยืนยันการจอง**

## 5. หลังจองเสร็จ

![จองห้องเรียบร้อย](images/u-success.jpg)

- ระบบแสดง **รหัสการจอง** เช่น `BR6910-5Y7M` กดไอคอนข้าง ๆ เพื่อคัดลอก **ควรเก็บรหัสนี้ไว้**
- **เพิ่มลงปฏิทิน** — บันทึกนัดลงปฏิทินในมือถือหรือ Outlook (ไฟล์ .ics)
- **พิมพ์ใบยืนยัน** — ใบยืนยันพร้อม QR Code
- **ดูการจองของฉัน** / **จองห้องอีกครั้ง**

### สถานะการจอง

| สถานะ           | ความหมาย                                                   |
| --------------- | ---------------------------------------------------------- |
| **อนุมัติแล้ว** | ได้ห้องแล้ว                                                |
| **รออนุมัติ**   | ห้องนี้ต้องให้ผู้ดูแลอนุมัติก่อน — เวลานี้ถูกกันไว้ให้แล้ว |
| **ไม่อนุมัติ**  | ผู้ดูแลไม่อนุมัติ (ดูเหตุผลในรายละเอียดการจอง)             |
| **ยกเลิก**      | ถูกยกเลิกโดยผู้จองหรือผู้ดูแล                              |

ระบบไม่ส่งอีเมลแจ้งผล ให้ตรวจสถานะที่เมนู **การจองของฉัน** (สถานะเปลี่ยนให้เองทันทีที่ผู้ดูแลอนุมัติ)

## 6. การจองของฉัน: แก้ไข ยกเลิก พิมพ์

![การจองของฉัน](images/u-my.jpg)

หน้านี้แสดงการจองที่ทำจากอุปกรณ์เครื่องนี้ แบ่งเป็นแท็บ **กำลังจะถึง · ที่ผ่านมา · ยกเลิก/ไม่อนุมัติ**

| ปุ่ม                | ใช้ทำอะไร                                                                                          |
| ------------------- | -------------------------------------------------------------------------------------------------- |
| **แก้ไข**           | เปลี่ยนเวลา ห้อง หรือรายละเอียด — ถ้าการจองที่อนุมัติแล้วถูกแก้ อาจต้องรออนุมัติใหม่               |
| **เพิ่มลงปฏิทิน**   | บันทึกลงปฏิทินในเครื่อง                                                                            |
| **พิมพ์**           | พิมพ์ใบยืนยันการจอง                                                                                |
| **ยกเลิกการจอง**    | ระบุเหตุผลได้ ถ้าเป็นการจองซ้ำ เลือกได้ว่า **เฉพาะครั้งนี้** หรือ **ครั้งนี้และครั้งถัดไปทั้งหมด** |
| **ลบจากอุปกรณ์นี้** | ซ่อนรายการจากเครื่องนี้เท่านั้น — **ไม่ได้ยกเลิกการจอง**                                           |

**ไม่ใช้ห้องแล้ว กรุณายกเลิก** เพื่อให้หน่วยงานอื่นจองต่อได้

### ดูการจองจากเครื่องอื่น

ถ้าจองจากคอมพิวเตอร์แต่อยากดูหรือยกเลิกจากมือถือ ให้กรอก **รหัสการจอง** และ **เบอร์โทรที่ใช้จอง** แล้วกด **ค้นหาและเพิ่ม**
การจองจะถูกเพิ่มเข้ามาในเครื่องนั้น (การจองซ้ำทั้งชุดจะถูกเพิ่มมาพร้อมกัน)

> ใส่เบอร์ผิดหลายครั้ง ระบบจะพักการค้นหารหัสนั้น 1 ชั่วโมง เพื่อป้องกันการเดา

### ดูรายละเอียดการจอง

กดที่รายการใดก็ได้ (ในหน้าแรก ปฏิทิน หรือการจองของฉัน) จะเห็นรายละเอียด ถ้าเป็นการจองของคุณจะมีป้าย “การจองของคุณ” และปุ่มจัดการ

![รายละเอียดการจอง](images/u-detail.jpg)

## 7. เช็คอินและคืนห้องก่อนเวลา

ใช้เมื่อสำนักงานเปิดใช้ฟังก์ชันเช็คอิน (สอบถามผู้ดูแล)

- **เช็คอินเข้าใช้ห้อง** — กดได้ตั้งแต่ก่อนเวลาเริ่มเล็กน้อย จากปุ่มในการจองของฉัน หรือที่จอหน้าห้อง
- **ถ้าไม่เช็คอินภายในเวลาที่กำหนดหลังเวลาเริ่ม ระบบจะคืนห้องอัตโนมัติ** ให้หน่วยงานอื่นจองต่อได้
- **คืนห้องก่อนเวลา** — ประชุมเสร็จเร็ว กดปุ่มนี้ ระบบจะปรับเวลาสิ้นสุดเป็นเวลาปัจจุบัน

## 8. จอแสดงผลหน้าห้อง

![จอแสดงผลหน้าห้อง](images/u-display.jpg)

แท็บเล็ตหน้าห้องแสดงสถานะตัวใหญ่ (ว่าง / ไม่ว่าง / ใกล้เริ่มประชุม) การประชุมปัจจุบันพร้อมแถบเวลา และกำหนดการวันนี้

- **จองห้องนี้** — จองจากหน้าจอได้ทันที
- **สแกน QR** ด้วยมือถือ เพื่อจองห้องนี้จากเครื่องของตนเอง
- เช็คอินจากจอได้เมื่อเปิดใช้การเช็คอิน

## 10. ตั้งค่าการแสดงผล

## 11. คำถามที่พบบ่อยและการแก้ปัญหา

| อาการ / คำถาม                               | วิธีแก้                                                                                                      |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| เปิดเว็บไม่ได้                              | ตรวจว่าพิมพ์ที่อยู่ถูก และ (ถ้าระบบอยู่ในสำนักงาน) เชื่อม Wi-Fi/LAN ของสำนักงานแล้ว ถ้ายังไม่ได้ แจ้งฝ่าย IT |
| เลือกวันที่ไม่ได้ (ขีดฆ่า)                  | เป็นวันหยุด เสาร์–อาทิตย์ หรือเกินช่วงที่เปิดให้จองล่วงหน้า                                                  |
| เลือกช่วงเวลาแล้วขึ้นว่า “ทับกับการจองอื่น” | มีการจองอยู่ในช่วงนั้น เลือกช่วงที่ว่างต่อเนื่องกัน                                                          |
| ระบบแจ้งว่า “เกินความจุห้อง”                | ลดจำนวน หรือเลือกห้องที่ใหญ่กว่า                                                                             |
| ระบบแจ้ง “จองจากอุปกรณ์นี้ถี่เกินไป”        | รอตามเวลาที่ระบบบอก หรือติดต่อผู้ดูแลห้องประชุม                                                              |
| ขึ้นข้อความ “ปิดรับการจองชั่วคราว”          | ผู้ดูแลกำลังปรับปรุงระบบ ยังดูปฏิทินได้ ลองจองใหม่ภายหลัง                                                    |
| ไม่เห็นการจองของตนเองในอีกเครื่อง           | ใช้ **ค้นหาและเพิ่ม** ด้วยรหัสการจองและเบอร์โทร (หัวข้อ 6)                                                   |
| ลืมรหัสการจอง                               | ดูจากใบยืนยัน/ปฏิทินที่บันทึกไว้ หรือติดต่อผู้ดูแลห้องประชุมพร้อมชื่อ วันที่ และเวลา                         |
| แก้ไขหรือยกเลิกไม่ได้                       | การประชุมเริ่มไปแล้ว หรือเลยกำหนดเวลายกเลิกล่วงหน้า หรือสำนักงานปิดฟังก์ชันนี้ไว้ — ติดต่อผู้ดูแลห้องประชุม  |
| การจองยังเป็น “รออนุมัติ”                   | รอผู้ดูแลอนุมัติ ถ้าใกล้เวลาประชุมแล้ว ติดต่อผู้ดูแลห้องประชุม                                               |
