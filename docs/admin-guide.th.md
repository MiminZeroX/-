# ส่วน ก — ผู้ดูแลระบบ

## 1. บทบาทและการเข้าสู่ระบบ

เปิด `ที่อยู่ระบบ/admin` (หรือกด **สำหรับผู้ดูแลระบบ** ท้ายหน้าเว็บ)

![หน้าเข้าสู่ระบบผู้ดูแล](images/a-login.jpg)

| สิทธิ์          | ใช้ได้                                                      |
| --------------- | ----------------------------------------------------------- |
| **ผู้ดูแลระบบ** | ทุกเมนู                                                     |
| **เจ้าหน้าที่** | แดชบอร์ด และรายการจอง (ดู เพิ่ม แก้ไข อนุมัติ ยกเลิกการจอง) |

### เข้าสู่ระบบครั้งแรก

- ติดตั้งครั้งแรก ระบบสุ่มรหัสผ่านของบัญชี `admin` ให้ (แสดงบนหน้าต่างระบบ และอยู่ในไฟล์ `data/initial-admin-password.txt`)
- ผู้ใช้ใหม่ทุกคนได้ **รหัสผ่านชั่วคราว** จากผู้ดูแล
- เข้าครั้งแรกระบบจะบังคับให้ **ตั้งรหัสผ่านของตนเอง** ก่อนใช้เมนูใด ๆ

![ตั้งรหัสผ่านใหม่เมื่อเข้าครั้งแรก](images/a-first-login.jpg)

### นโยบายรหัสผ่าน

- อย่างน้อย **12 ตัวอักษร** แนะนำให้ใช้วลีที่จำง่าย เช่น `ห้องประชุม-ชั้นสี่-2569` หรือ `Room-Desk-Phrase-31`
- ห้ามเป็นรหัสที่เดาง่าย (เช่น `password1234`, `bangrak@2569`) ห้ามมีชื่อผู้ใช้หรือชื่อตนเองอยู่ในรหัส
- ใส่รหัสผิดหลายครั้ง ระบบจะพักการเข้าสู่ระบบชั่วคราว (นับทั้งต่ออุปกรณ์และต่อบัญชี)

### ความปลอดภัยของเซสชัน

- ออกจากระบบอัตโนมัติเมื่อไม่ใช้งานตามเวลาที่ตั้งไว้ (ค่าเริ่มต้น 12 ชั่วโมง)
- เซสชันผูกกับเครือข่ายที่เข้าสู่ระบบ ถ้าเครือข่ายของเครื่องเปลี่ยน (เช่น สลับ Wi-Fi ↔ 4G) ต้องเข้าสู่ระบบใหม่
- รายการสำคัญต้อง **ยืนยันรหัสผ่านซ้ำ**: เพิ่มผู้ใช้ เปลี่ยนสิทธิ์ ตั้งรหัสให้ผู้อื่น กู้คืนข้อมูล สร้างรหัสจอใหม่
- เปลี่ยนรหัสผ่านของตนเองได้ที่ **เปลี่ยนรหัสผ่าน** มุมล่างซ้าย

## 2. แดชบอร์ด

![แดชบอร์ด](images/a-dash.jpg)

- ตัวเลขสรุป: การประชุมวันนี้ · รออนุมัติ · การจองเดือนนี้ · อัตราการใช้ห้องเฉลี่ย
- **การจองรายวัน** (เลื่อนดูเดือนอื่นได้) · **รออนุมัติ** พร้อมปุ่มอนุมัติ ✓ / ไม่อนุมัติ ✕ ทันที
- อัตราการใช้ห้อง · สถานะการจองในเดือน · ช่วงเวลาที่มีการใช้ห้องมาก · หน่วยงานที่ใช้ห้องมากที่สุด · กำหนดการวันนี้
- เมื่อมีคำขอจองใหม่ที่รออนุมัติ หน้าผู้ดูแลที่เปิดค้างไว้จะแจ้งเตือนทันที (ข้อความ + เสียง)

## 3. รายการจอง: อนุมัติ แก้ไข ยกเลิก

![รายการจอง](images/a-bookings.jpg)

- แท็บด่วน: **กำลังจะถึง · รออนุมัติ · วันนี้ · สัปดาห์นี้ · เดือนนี้ · ทั้งหมด**
- ค้นหาด้วยรหัส หัวข้อ ชื่อผู้จอง หน่วยงาน เบอร์โทร และกรองตามห้อง สถานะ ช่วงวันที่
- ติ๊กหลายรายการเพื่อ อนุมัติ / ไม่อนุมัติ / ยกเลิก พร้อมกัน
- ปุ่มด้านบน:
  - **ปิดใช้ห้อง** — กันห้องไว้ (เช่น ซ่อมบำรุง งานพิธี) ผู้ใช้จะเห็นเป็น “ปิดใช้ห้อง” และจองทับไม่ได้
  - **ส่งออก CSV** — เปิดด้วย Excel ได้ (ภาษาไทยไม่เพี้ยน)
  - **เพิ่มการจอง** — จองแทนผู้ใช้ ติ๊ก **ข้ามกฎการจอง** ได้เมื่อจำเป็น (เวลาทำการ วันหยุด ความจุ ระยะเวลา — แต่ยังตรวจการจองซ้อนเสมอ)

กดที่รายการเพื่อดูรายละเอียดและประวัติการดำเนินการ

![รายละเอียดการจอง](images/a-booking-detail.jpg)

| ปุ่ม           | ผล                                                                 |
| -------------- | ------------------------------------------------------------------ |
| **อนุมัติ**    | สถานะเป็น “อนุมัติแล้ว” ผู้จองเห็นผลทันที                          |
| **ไม่อนุมัติ** | ระบุเหตุผลได้ ผู้จองเห็นเหตุผลในรายละเอียดการจอง                   |
| **แก้ไข**      | แก้ได้ทุกช่อง รวมห้องและเวลา                                       |
| **ยกเลิก**     | เก็บประวัติไว้ (แนะนำ)                                             |
| **ลบถาวร**     | ลบออกจากระบบและกู้คืนไม่ได้ — ใช้เฉพาะรายการทดสอบหรือรายการผิดพลาด |

> ระบบไม่ส่งอีเมล/SMS แจ้งผู้จอง ผู้จองดูสถานะได้จากเมนู “การจองของฉัน” ถ้าเปลี่ยนแปลงกะทันหันควรโทรแจ้งตามเบอร์ในรายการ

## 4. ห้องประชุม

![ห้องประชุม](images/a-rooms.jpg)

- **เพิ่มห้องประชุม** / **แก้ไข** / **นำออก** (ห้องที่นำออกจะไม่แสดง แต่ประวัติการจองยังอยู่)
- สวิตช์ **เปิดให้บริการ** — ปิดชั่วคราวได้ พร้อมข้อความแจ้งผู้ใช้ เช่น “ปิดปรับปรุงถึง 15 พ.ย.”
- **จอหน้าห้อง** — เปิดหน้าจอแสดงผลของห้องนั้น

![แก้ไขห้องประชุม](images/a-room-form.jpg)

| ช่อง               | หมายเหตุ                                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------------ |
| ชื่อห้อง / ชั้น    |                                                                                                              |
| ความจุ (คน)        | ใช้ตรวจจำนวนผู้เข้าร่วม (ถ้าเปิด “จำกัดผู้เข้าร่วมไม่เกินความจุห้อง”)                                        |
| การอนุมัติ         | **ตามค่าระบบ** / **ต้องอนุมัติเสมอ** / **ยืนยันทันทีเสมอ** — เช่น ให้ห้องใหญ่ต้องอนุมัติ ห้องเล็กยืนยันทันที |
| คำอธิบาย / สี      | สีชุดแนะนำแยกแยะได้แม้ผู้มีภาวะตาบอดสี                                                                       |
| อุปกรณ์ที่มีในห้อง | แสดงบนการ์ดห้อง และติดป้าย “มีในห้อง” ในแบบฟอร์มจอง                                                          |

## 5. หน่วยงานและวันหยุด

![หน่วยงานและวันหยุด](images/a-data.jpg)

- **รายชื่อหน่วยงาน** — ตัวเลือกในแบบฟอร์มจอง เพิ่ม/ลบ/เรียงลำดับ แล้วกด **บันทึกรายชื่อหน่วยงาน**
- **วันหยุดราชการ** — วันที่อยู่ในรายการจะจองไม่ได้ (ถ้าไม่ได้เปิดให้จองวันหยุด)
  - **เติมวันหยุดที่วันที่ตายตัวของปีนี้** — เพิ่มวันขึ้นปีใหม่ สงกรานต์ วันแม่ ฯลฯ ในคลิกเดียว
  - **ต้องเพิ่มเองทุกปี:** วันหยุดทางจันทรคติ (มาฆบูชา วิสาขบูชา อาสาฬหบูชา เข้าพรรษา) วันหยุดชดเชย และวันหยุดพิเศษตามมติ ครม.
  - กด **บันทึกวันหยุด** ทุกครั้ง

## 6. ตั้งค่าและฟังก์ชัน

![ตั้งค่าและฟังก์ชัน](images/a-settings.jpg)

การเปลี่ยนแปลงมีผลกับทุกอุปกรณ์ทันทีหลังกดบันทึก และถูกบันทึกใน Log

| หมวด                           | การตั้งค่าหลัก (ค่าเริ่มต้น)                                                                                                                                                                                                                                                                                         |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ข้อมูลหน่วยงาน**             | ชื่อหน่วยงาน ชื่อระบบ ข้อความรอง ข้อมูลติดต่อ (แสดงท้ายหน้าและในใบยืนยัน) โลโก้ (PNG/JPG/SVG ≤ 300KB; ไม่ใส่ = ใช้ตราสำนักงานเขต)                                                                                                                                                                                    |
| **ประกาศหน้าแรก**              | เปิด/ปิด รูปแบบ (ข้อมูล/สำเร็จ/เตือน/สำคัญ) ข้อความประกาศ                                                                                                                                                                                                                                                            |
| **เวลาและกฎการจอง**            | เวลาเปิด–ปิด (08:00–18:00) ช่วงเวลาย่อย (30 นาที) จองขั้นต่ำ (30 นาที) สูงสุดต่อครั้ง (600 นาที) เวลาเว้นระหว่างประชุม (0) จองล่วงหน้าไม่เกิน (90 วัน) ต้องจองก่อนเวลาเริ่ม (0 นาที) เปิดจองเสาร์–อาทิตย์ (ปิด) เปิดจองวันหยุดราชการ (ปิด)                                                                           |
| **ฟังก์ชันการจอง**             | ต้องได้รับอนุมัติก่อน (ปิด) ผู้จองแก้ไขเองได้ (เปิด) ผู้จองยกเลิกเองได้ (เปิด) ต้องยกเลิกล่วงหน้าอย่างน้อย (0) การจองซ้ำ (เปิด, สูงสุด 12 ครั้ง) จำกัดผู้เข้าร่วมไม่เกินความจุ (เปิด) บังคับเบอร์โทร (เปิด) บังคับอีเมล (ปิด) การจองค้างสูงสุดต่อเบอร์ (0 = ไม่จำกัด) ป้องกันการจองถี่ผิดปกติ (30 ครั้ง/ชม./เครื่อง) |
| **ความเป็นส่วนตัว**            | แสดงหัวข้อการประชุมในปฏิทิน (เปิด) แสดงชื่อผู้จองในปฏิทิน (เปิด) — เบอร์โทรและอีเมลไม่แสดงต่อสาธารณะเสมอ                                                                                                                                                                                                             |
| **เช็คอินและคืนห้องอัตโนมัติ** | เปิดใช้การเช็คอิน (ปิด) เช็คอินได้ก่อนเวลาเริ่ม (15 นาที) คืนห้องอัตโนมัติหากไม่เช็คอินภายใน (15 นาที; 0 = ไม่คืน)                                                                                                                                                                                                   |
| **อุปกรณ์และบริการเสริม**      | รายการตัวเลือกที่ผู้จองกดขอได้                                                                                                                                                                                                                                                                                       |
| **ระเบียบการใช้ห้องประชุม**    | ข้อความที่ผู้จองต้องกดยอมรับ (เว้นว่าง = ไม่แสดง)                                                                                                                                                                                                                                                                    |
| **รูปลักษณ์และเอฟเฟกต์**       | สีหลัก (น้ำเงิน) ธีมเริ่มต้น (ตามอุปกรณ์) เอฟเฟกต์การเคลื่อนไหว (เต็มรูปแบบ) สั่นเมื่อกดปุ่ม เสียงคลิก พลุกระดาษเมื่อจองสำเร็จ                                                                                                                                                                                       |
| **จอแสดงผลหน้าห้อง**           | เปิดใช้จอหน้าห้อง (เปิด) แสดงหัวข้อการประชุมบนจอ (เปิด)                                                                                                                                                                                                                                                              |
| **ระบบและความปลอดภัย**         | ปิดรับการจองชั่วคราว (โหมดปรับปรุง) + ข้อความแจ้ง · เสียงแจ้งเตือนคำขอจองใหม่ · ออกจากระบบอัตโนมัติ (12 ชม.) · เก็บบันทึกกิจกรรม (365 วัน) · เก็บไฟล์สำรองอัตโนมัติ (30 วัน)                                                                                                                                         |

> **ป้องกันการจองถี่ผิดปกติ** นับต่ออุปกรณ์ ถ้าระบบอยู่บนคลาวด์และทุกเครื่องในสำนักงานออกเน็ตด้วย IP เดียวกัน ให้ฝ่าย IT กำหนด IP สำนักงาน (หัวข้อ 14) เพื่อไม่ให้ทั้งสำนักงานถูกจำกัดพร้อมกัน

## 7. ผู้ใช้งานระบบ

![เพิ่มผู้ใช้](images/a-users.jpg)

- **เพิ่มผู้ใช้:** ชื่อผู้ใช้ (ภาษาอังกฤษ) ชื่อ–นามสกุล สิทธิ์ รหัสผ่านชั่วคราว (กด **สุ่มรหัส** ได้) และ **รหัสผ่านของคุณ** เพื่อยืนยันตัวตน
- แจ้งรหัสชั่วคราวทางช่องทางส่วนตัว ผู้ใช้จะต้องตั้งรหัสใหม่เมื่อเข้าครั้งแรก
- **แก้ไข:** เปลี่ยนชื่อ สิทธิ์ ตั้งรหัสผ่านใหม่ให้ ปิดการใช้งาน หรือลบบัญชี
- เจ้าหน้าที่ย้ายงาน/ลาออก ให้ **ปิดการใช้งาน** ทันที (ประวัติใน Log ยังอยู่)
- ควรมีบัญชี **ผู้ดูแลระบบ อย่างน้อย 2 คน** เผื่อกรณีลืมรหัสผ่าน

## 8. บันทึกกิจกรรม (Log)

![บันทึกกิจกรรม](images/a-logs.jpg)

- บันทึกทุกการจอง แก้ไข อนุมัติ ยกเลิก การเข้าสู่ระบบ (รวมครั้งที่ผิด) การเปลี่ยนการตั้งค่า และผู้ใช้ พร้อมเวลา ผู้ทำรายการ IP และอุปกรณ์
- กรองตามระดับ (ทั่วไป/คำเตือน/ความปลอดภัย/ข้อผิดพลาด) ประเภท และช่วงวันที่ · **ส่งออก CSV**
- **ล้างบันทึกเก่า** — ระบบเก็บ 30 วันล่าสุดไว้เสมอ (ลบย้อนหลังไม่ได้) และลบเกินระยะเวลาที่ตั้งไว้ให้อัตโนมัติ
- ควรตรวจรายการระดับ **ความปลอดภัย** เป็นระยะ เช่น เข้าสู่ระบบผิดซ้ำ ๆ หรือเซสชันถูกใช้จาก IP อื่น

## 9. สำรอง/กู้คืนข้อมูล

![สำรองและกู้คืนข้อมูล](images/a-backup.jpg)

- **ดาวน์โหลดไฟล์สำรองตอนนี้** — ไฟล์ .json (การจอง ห้อง การตั้งค่า หน่วยงาน วันหยุด รายชื่อผู้ดูแล **ไม่รวมรหัสผ่าน**) ติ๊กรวม Log ได้
- **ไฟล์สำรองอัตโนมัติ** — ระบบสำรองวันละครั้ง เก็บไว้ตามจำนวนวันที่ตั้ง ดาวน์โหลดย้อนหลังได้
- **กู้คืนจากไฟล์สำรอง** — ข้อมูลปัจจุบันถูกแทนที่ทั้งหมด (ระบบสำรองข้อมูลปัจจุบันไว้ให้อัตโนมัติก่อน) ต้องยืนยันรหัสผ่าน
  - **บัญชีผู้ใช้ไม่ถูกแทนที่** — ผู้ใช้เดิมของเครื่องปลายทางยังใช้ได้
- **ข้อมูลระบบ** — เวลาทำงานต่อเนื่อง จำนวนรายการ ขนาดข้อมูล หน่วยความจำ และโฟลเดอร์เก็บข้อมูล

**แนะนำ:** ดาวน์โหลดไฟล์สำรองเก็บไว้นอกเครื่องแม่ข่าย **อย่างน้อยสัปดาห์ละครั้ง**

## 12. รูปแบบการติดตั้ง

### แบบ ก — เครื่องในสำนักงาน (Wi-Fi/LAN)

1. ติดตั้ง Node.js รุ่น LTS จาก <https://nodejs.org>
2. แตกไฟล์ระบบไว้ในโฟลเดอร์ถาวร เช่น `D:\bangrak-room-booking`
3. Windows: ดับเบิลคลิก `start-windows.bat` · macOS/Linux: `./start.sh`
4. อนุญาตใน Windows Defender Firewall (Private networks)
5. ตั้ง IP คงที่ให้เครื่อง (Static IP / DHCP reservation) เพื่อให้ QR ใช้ได้ตลอด
6. ให้เปิดเองเมื่อเปิดเครื่อง: ดับเบิลคลิก `windows-autostart.bat` หนึ่งครั้ง
7. ตั้งค่าเครื่องไม่ให้ Sleep

ข้อดี: ข้อมูลอยู่ในสำนักงาน · ข้อจำกัด: ใช้ได้เฉพาะในเครือข่ายสำนักงาน เครื่องต้องเปิดตลอด

### แบบ ข — เครื่องคลาวด์ (ใช้ได้จากทุกที่ + HTTPS)

ใช้สคริปต์ติดตั้งคำสั่งเดียวบน VM Ubuntu 22.04/24.04 — ขั้นตอนเต็มอยู่ใน [deploy/README.md](../deploy/README.md)

```bash
sudo bash deploy/install-vm.sh --domain=booking.example.go.th --office-ips=<IP สาธารณะของสำนักงาน>
```

สคริปต์ติดตั้ง Node.js, Caddy (ใบรับรอง Let's Encrypt ต่ออายุอัตโนมัติ), บริการ systemd ที่จำกัดสิทธิ์, ไฟร์วอลล์ และเปิดระบบที่ `127.0.0.1:3000` หลัง Caddy

> ระบบเก็บชื่อและเบอร์โทรผู้จอง (ข้อมูลส่วนบุคคลตาม PDPA) — ตรวจนโยบายการใช้คลาวด์ของหน่วยงานก่อน

## 13. เปิดใช้ HTTPS

ระบบรันเป็น **HTTP** โดยค่าเริ่มต้น หน้าต่างระบบจะแสดง `http://...` และหมายเหตุให้เปิด HTTPS

| สถานการณ์                        | วิธี                                                              |  เบราว์เซอร์ทุกเครื่องเชื่อถือทันที  |
| -------------------------------- | ----------------------------------------------------------------- | :----------------------------------: |
| เครื่องคลาวด์ + ชื่อโดเมน        | `deploy/install-vm.sh` (Caddy + Let's Encrypt อัตโนมัติ)          |                 ใช่                  |
| ในสำนักงาน มีใบรับรองของหน่วยงาน | `node server.js --port=443 --tls-cert=cert.pem --tls-key=key.pem` |     ใช่ (ถ้า CA เป็นที่เชื่อถือ)     |
| ในสำนักงาน ไม่มีใบรับรอง         | `./start.sh --https` / `start-windows.bat --https` (ด้านล่าง)     | ไม่ — ต้องติดตั้ง root CA ทุกเครื่อง |

### เปิด HTTPS ด้วยคำสั่งเดียว (เครื่องในสำนักงาน หรือทดสอบบน Mac/PC)

ติดตั้ง mkcert ครั้งแรกครั้งเดียว แล้วเปิดระบบด้วย `--https`

```bash
# macOS:   brew install mkcert
# Windows: winget install FiloSottile.mkcert   (หรือ choco install mkcert)
# Ubuntu:  sudo apt install mkcert libnss3-tools
./start.sh --https            # macOS/Linux
start-windows.bat --https     # Windows (สร้าง shortcut ที่ใส่ --https ต่อท้ายไว้ได้)
```

- ระบบสร้างใบรับรองใน `data/certs/` ให้อัตโนมัติ ครอบคลุม `localhost` ชื่อเครื่อง และ IP ทุกวงของเครื่อง — **สร้างใหม่เองเมื่อ IP เปลี่ยน**
- ครั้งแรก `mkcert -install` อาจถามรหัสผ่านเครื่อง เพื่อให้เครื่องนี้เชื่อถือใบรับรอง
- พอร์ต: macOS/Windows ใช้ 443 (เปิดด้วย `https://<IP เครื่องแม่ข่าย>` ไม่ต้องพิมพ์เลขพอร์ต) · Linux ที่ไม่ใช่ root ใช้ 3443 · กำหนดเองได้ด้วย `--port=`
- เครื่องอื่น (มือถือ/คอมของเจ้าหน้าที่) ต้องติดตั้งไฟล์ `rootCA.pem` (ตำแหน่งแสดงบนหน้าต่างระบบตอนสร้างใบรับรอง หรือดูด้วย `mkcert -CAROOT`) จึงจะไม่ขึ้นคำเตือน
- ไฟล์ใบรับรองอยู่ใน `data/` ซึ่งไม่ถูกเก็บใน git — **ห้ามส่งต่อ `rootCA-key.pem`**
- เมื่อเปิด HTTPS คุกกี้เข้าสู่ระบบจะถูกตั้งเป็น `Secure`
- พิมพ์ `--https` ต่อท้าย `node server.js` โดยตรงจะไม่มีผล (ระบบจะแจ้งว่าไม่รู้จักตัวเลือก) — ต้องใช้ผ่าน `start.sh` / `start-windows.bat`

## 14. ตัวเลือกการเปิดระบบ

ส่งเป็นอาร์กิวเมนต์ `--ชื่อ=ค่า` หรือตัวแปรแวดล้อม (บนคลาวด์อยู่ในไฟล์ `/etc/bangrak-booking.env`)

| อาร์กิวเมนต์             | ตัวแปร               | ค่าเริ่มต้น | ใช้ทำอะไร                                                                                      |
| ------------------------ | -------------------- | ----------- | ---------------------------------------------------------------------------------------------- |
| `--port`                 | `PORT`               | 3000        | พอร์ต                                                                                          |
| `--host`                 | `HOST`               | 0.0.0.0     | อินเทอร์เฟซที่รับการเชื่อมต่อ (หลัง proxy ใช้ `127.0.0.1`)                                     |
| `--data`                 | `DATA_DIR`           | `./data`    | โฟลเดอร์ข้อมูล                                                                                 |
| `--allowed-hosts`        | `ALLOWED_HOSTS`      | —           | ชื่อโดเมนที่อนุญาต (นอกจาก IP/localhost/ชื่อเครื่อง) เช่น `booking.bangrak.local,*.office.lan` |
| `--tls-cert` `--tls-key` | `TLS_CERT` `TLS_KEY` | —           | เปิด HTTPS ด้วยไฟล์ใบรับรอง                                                                    |
| `--public-url`           | `PUBLIC_URL`         | —           | ที่อยู่สาธารณะ (คลาวด์) ใช้ทำลิงก์/QR, คุกกี้ Secure และเพิ่มชื่อโดเมนให้อัตโนมัติ             |
| `--trust-proxy`          | `TRUST_PROXY`        | —           | proxy ที่เชื่อถือ เช่น `loopback` — ระบบจะอ่าน IP จริงของผู้ใช้จาก `X-Forwarded-For`           |
| `--office-ips`           | `OFFICE_IPS`         | —           | IP/เครือข่ายสาธารณะของสำนักงาน (คั่นด้วย `,` ใส่ CIDR ได้) ผ่อนเพดานการใช้งานต่อ IP 20 เท่า    |

## 15. ข้อมูล การสำรอง และการย้ายเครื่อง

| ไฟล์ (ใน `data/`)            | เนื้อหา                                                                   |
| ---------------------------- | ------------------------------------------------------------------------- |
| `db.json`                    | การจอง ห้อง การตั้งค่า หน่วยงาน วันหยุด บัญชีผู้ดูแล (รหัสผ่านแฮช scrypt) |
| `logs.json`                  | บันทึกกิจกรรม                                                             |
| `backups/`                   | ไฟล์สำรองอัตโนมัติรายวัน และไฟล์สำรองก่อนการกู้คืน                        |
| `initial-admin-password.txt` | รหัสผ่านเริ่มต้น (ถูกลบอัตโนมัติหลังตั้งรหัสใหม่)                         |
| `server.pid`                 | บอกว่าระบบกำลังทำงาน                                                      |

บนคลาวด์โฟลเดอร์ข้อมูลคือ `/var/lib/bangrak-booking`

**ย้ายเครื่องแม่ข่าย (ข้อมูลครบรวมบัญชีผู้ใช้):** ปิดระบบ → คัดลอกทั้งโฟลเดอร์ `data/` ไปเครื่องใหม่ → เปิดระบบ
**ย้ายเฉพาะข้อมูลการจอง:** ใช้เมนูสำรอง/กู้คืน (บัญชีผู้ใช้ไม่ถูกย้าย)

**กลยุทธ์การสำรองที่แนะนำ**

1. ระบบสำรองรายวันใน `data/backups/` อัตโนมัติ (อยู่บนดิสก์เดียวกัน)
2. ดาวน์โหลดไฟล์สำรองจากหน้าผู้ดูแลเก็บไว้นอกเครื่อง สัปดาห์ละครั้ง
3. บนคลาวด์: เปิด Snapshot/Backup ของผู้ให้บริการ · ในสำนักงาน: สำรองโฟลเดอร์ `data/` ไปยัง NAS/ไดรฟ์กลาง
4. ทดลองกู้คืนบนเครื่องทดสอบ ปีละครั้ง

## 17. ความปลอดภัย

ระบบผ่านการทดสอบเจาะระบบและตรวจโค้ดตาม OWASP Top 10 แล้ว (รายละเอียดใน `README.md` หัวข้อ “ความปลอดภัย”) สิ่งที่ฝ่าย IT ควรทำ:

- [ ] กำหนด `OFFICE_IPS` เมื่ออยู่บนคลาวด์ และพิจารณา `--admin-office-only` ให้หน้าผู้ดูแลเปิดได้เฉพาะในสำนักงาน
- [ ] จำกัดสิทธิ์โฟลเดอร์ `data/` ให้เฉพาะบัญชีที่รันระบบ
- [ ] ผู้ดูแลทุกคนใช้รหัสผ่านของตนเอง ไม่ใช้บัญชีร่วมกัน · ปิดบัญชีผู้ที่ย้ายงานทันที
- [ ] อัปเดต Node.js รุ่น LTS และระบบปฏิบัติการตามรอบ
- [ ] ตรวจ Log ระดับ “ความปลอดภัย” เป็นประจำ
- [ ] PDPA: ระบบเก็บชื่อ หน่วยงาน เบอร์โทร (และอีเมลถ้าเปิด) ของผู้จอง — กำหนดระยะเวลาเก็บ และผู้มีสิทธิ์เข้าถึงไฟล์สำรอง

## 18. แก้ปัญหา

| อาการ                                                 | สาเหตุ / วิธีแก้                                                                                                                                                                                                                                             |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| เครื่องอื่นเปิดไม่ได้ (ในสำนักงาน)                    | อยู่คนละเครือข่าย / Firewall บล็อก — Windows: `netsh advfirewall firewall add rule name="BangRak Room Booking" dir=in action=allow protocol=TCP localport=3000`                                                                                              |
| IP เปลี่ยน QR ใช้ไม่ได้                               | ตั้ง IP คงที่ หรือ DHCP reservation ที่เราเตอร์                                                                                                                                                                                                              |
| “พอร์ตถูกใช้งานอยู่แล้ว”                              | มีโปรแกรมอื่นใช้พอร์ต หรือระบบเปิดซ้อน — ใช้ `--port=3001` หรือปิดตัวที่เปิดอยู่                                                                                                                                                                             |
| ขึ้น 421 / “ชื่อโฮสต์นี้ไม่ได้รับอนุญาต”              | เปิดผ่านชื่อโดเมนที่ไม่ได้อนุญาต — เพิ่มด้วย `--allowed-hosts=` (หรือ `--public-url=` บนคลาวด์)                                                                                                                                                              |
| ยังเป็น `http://`                                     | ยังไม่ได้เปิด HTTPS — เปิดระบบด้วย `./start.sh --https` (หัวข้อ 13)                                                                                                                                                                                          |
| ลืมรหัสผ่านผู้ดูแลทุกคน                               | ปิดระบบ → `node scripts/reset-admin.js` (คลาวด์: `sudo systemctl stop bangrak-booking && sudo -u bangrak node /opt/bangrak-booking/scripts/reset-admin.js --data=/var/lib/bangrak-booking && sudo systemctl start bangrak-booking`) → ใช้รหัสชั่วคราวที่แสดง |
| ทั้งสำนักงานถูกพักการเข้าสู่ระบบ/จองพร้อมกัน (คลาวด์) | ยังไม่ได้ตั้ง `OFFICE_IPS` หรือ proxy ไม่ได้ส่ง IP จริง — ดู deploy/README.md ขั้นที่ 4                                                                                                                                                                      |
| ผู้ดูแลหลุดออกจากระบบบ่อย                             | เครือข่ายของเครื่องเปลี่ยน IP (มือถือ 4G/5G) — ระบบตั้งใจให้เข้าใหม่เพื่อความปลอดภัย                                                                                                                                                                         |
| แท็บเล็ตหน้าห้องดับเอง / ปุ่มเช็คอินไม่ทำงาน          | ตั้งไม่ให้ล็อกจอ · เปิดลิงก์จอจากเมนู “การเชื่อมต่อและ QR” ใหม่ (รหัสจออาจถูกสร้างใหม่)                                                                                                                                                                      |
| ดูการทำงาน/ข้อผิดพลาด                                 | ในสำนักงาน: หน้าต่างระบบ · คลาวด์: `journalctl -u bangrak-booking -f` และ `journalctl -u caddy`                                                                                                                                                              |
