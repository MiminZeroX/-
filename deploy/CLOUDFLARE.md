# รันระบบบน Cloudflare (ไม่ต้องเปิดเครื่องในสำนักงาน)

ระบบทั้งหมดทำงานบน Cloudflare: ไม่ต้องมีเครื่องแม่ข่าย ไม่ต้องเปิดเครื่องทิ้งไว้ ได้ HTTPS และลิงก์ถาวรทันที
เมื่อแก้โค้ดแล้ว push เข้า `main` บน GitHub Cloudflare จะดึงโค้ดไป deploy ให้เอง

```
ผู้ใช้ ──HTTPS──▶ Cloudflare Worker (worker/index.js)
                    ├─ หน้าเว็บ (public/) ← Static Assets พร้อม header ความปลอดภัย
                    └─ /api/*  ─▶ Durable Object (ตัวเดียว)
                                   ├─ ระบบเดิมทั้งหมด (src/app.js)
                                   └─ ข้อมูลใน SQLite ของ Cloudflare (การจอง ผู้ใช้ บันทึกกิจกรรม ไฟล์สำรอง)
```

ระบบแบบเครื่องในสำนักงาน (`start-windows.bat` / `start.sh`) และแบบเครื่อง VM (`deploy/install-vm.sh`) ยังใช้ได้เหมือนเดิม

---

## 1) ตั้งค่า Workers Builds (ทำครั้งเดียว)

ใน Cloudflare dashboard › **Workers & Pages** › `bangrak-room-booking` › **Settings** › **Build**

| ช่อง           | ค่า                   |
| -------------- | --------------------- |
| Git repository | `MiminZeroX/-`        |
| Branch         | `main`                |
| Build command  | (เว้นว่าง)            |
| Deploy command | `npx wrangler deploy` |
| Root directory | `/`                   |

ไฟล์ตั้งค่าอยู่ใน `wrangler.jsonc` แล้ว ไม่ต้องตั้งอย่างอื่น

## 2) ตั้งรหัสผ่านผู้ดูแลเริ่มต้น — **ก่อนเปิดเว็บครั้งแรก**

**Settings** › **Variables and Secrets** › **Add** › ประเภท **Secret**

| ชื่อ                     | ค่า                                                      |
| ------------------------ | -------------------------------------------------------- |
| `ADMIN_INITIAL_PASSWORD` | รหัสผ่านชั่วคราวของบัญชี `admin` (อย่างน้อย 12 ตัวอักษร) |

- ระบบสร้างข้อมูลเริ่มต้นตอนเปิดเว็บครั้งแรก และใช้ค่านี้เป็นรหัสผ่านของ `admin`
- เข้า `https://<ลิงก์ของคุณ>/admin` แล้วระบบจะบังคับให้ตั้งรหัสผ่านใหม่ทันที
- ถ้าลืมตั้ง: บัญชี `admin` จะยังเข้าไม่ได้ (ระบบไม่แสดงรหัสที่สุ่มไว้ใน Log เพื่อความปลอดภัย) — ตั้ง Secret `ADMIN_RESET_PASSWORD` แล้วเปิดเว็บอีกครั้ง

## 3) ตั้งค่าเพิ่มเติม (ไม่บังคับ)

| ชื่อ (ประเภท Variable) | ใช้ทำอะไร                                                                                                                                                                            |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `OFFICE_IPS`           | IP สาธารณะของสำนักงาน คั่นด้วย `,` — ทุกเครื่องในสำนักงานใช้ IP เดียวกัน ระบบจะผ่อนเพดานการใช้งานให้ ไม่ให้คนหนึ่งทำให้ทั้งสำนักงานถูกจำกัด (ดู IP ได้ที่หน้าผู้ดูแล › การเชื่อมต่อ) |
| `PUBLIC_URL`           | ที่อยู่เว็บหลัก ถ้าใช้โดเมนของหน่วยงาน เช่น `https://booking.example.go.th`                                                                                                          |

Secret `UPDATE_TOKEN` ของระบบส่งต่อไป Quick Tunnel แบบเดิม **ไม่ใช้แล้ว** ลบได้

## 4) ย้ายข้อมูลจากเครื่องเดิม

1. เครื่องเดิม: หน้าผู้ดูแล › **สำรอง/กู้คืนข้อมูล** › **ดาวน์โหลดไฟล์สำรองตอนนี้** (ติ๊กรวมบันทึกกิจกรรมได้)
2. บน Cloudflare: เข้าสู่ระบบ › **สำรอง/กู้คืนข้อมูล** › เลือกไฟล์นั้น › ยืนยันรหัสผ่าน
3. บัญชีผู้ใช้ไม่ถูกย้าย (ไฟล์สำรองไม่มีรหัสผ่าน) — สร้างบัญชีเจ้าหน้าที่ใหม่ในเมนู **ผู้ใช้งานระบบ**

## 5) การดูแล

| ต้องการ                     | ทำอย่างไร                                                                                                                                                                        |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| อัปเดตระบบ                  | merge โค้ดเข้า `main` — Cloudflare deploy ให้เอง (ดูผลที่ **Deployments**) ข้อมูลไม่หาย                                                                                          |
| ย้อนกลับเวอร์ชัน            | **Deployments** › เลือกเวอร์ชันก่อนหน้า › **Rollback**                                                                                                                           |
| สำรองข้อมูล                 | ระบบสำรองอัตโนมัติวันละครั้ง (เก็บตามจำนวนวันที่ตั้ง) — ควรดาวน์โหลดเก็บไว้นอก Cloudflare สัปดาห์ละครั้ง                                                                         |
| ดูการทำงาน/ข้อผิดพลาด       | **Workers** › `bangrak-room-booking` › **Logs**                                                                                                                                  |
| ใช้โดเมนของหน่วยงาน         | **Settings** › **Domains & Routes** › **Add** › Custom domain แล้วตั้ง `PUBLIC_URL` ให้ตรง                                                                                       |
| **ลืมรหัสผ่านผู้ดูแลทุกคน** | เพิ่ม Secret `ADMIN_RESET_PASSWORD` = รหัสชั่วคราว แล้วเปิดเว็บ บัญชี `admin` จะถูกรีเซ็ตเป็นรหัสนั้น (ครั้งเดียวต่อค่าที่ตั้ง) เข้าสู่ระบบแล้วตั้งรหัสใหม่ จากนั้นลบ Secret ได้ |

## 6) ค่าใช้จ่ายและข้อจำกัด

- ขนาดสำนักงานเขตอยู่ในโควตาฟรีของ Cloudflare สบาย ๆ (คำขอหลักพันต่อวัน ข้อมูลไม่กี่ MB)
- การตรวจรหัสผ่านตอนเข้าสู่ระบบใช้การคำนวณหนักโดยตั้งใจ (กันการเดารหัส) ถ้าเข้าสู่ระบบผู้ดูแลแล้วขึ้นข้อผิดพลาดเรื่องเวลา CPU เกิน (Error 1102) ให้เปลี่ยนเป็น **Workers Paid** (ประมาณ 5 ดอลลาร์/เดือน)
- การอัปเดตสดจะต่อใหม่เองทุก 2 นาที (ผู้ใช้ไม่เห็นความต่าง) เพื่อไม่ให้การเชื่อมต่อของหน้าที่ปิดไปแล้วค้างนับ
- ข้อมูลอยู่บน Cloudflare (ข้อมูลส่วนบุคคลตาม PDPA: ชื่อ หน่วยงาน เบอร์โทรผู้จอง) — แจ้งฝ่ายเทคโนโลยีสารสนเทศของหน่วยงานก่อนใช้งานจริง

## ทดสอบในเครื่องก่อน deploy (สำหรับนักพัฒนา)

```bash
npx wrangler dev --var ADMIN_INITIAL_PASSWORD:first-run-pass-77
# เปิด http://localhost:8787
```
