# เปิดระบบจองห้องประชุมผ่านอินเทอร์เน็ต (เครื่องคลาวด์ + HTTPS)

ใช้เมื่อต้องการให้เจ้าหน้าที่เปิดระบบได้จากทุกที่ ทั้งในและนอกสำนักงาน
ระบบจะทำงานบนเครื่องเสมือน (VM) เพียงเครื่องเดียว รองรับผู้ใช้พร้อมกันได้หลายร้อยคน

```
ผู้ใช้ ──HTTPS──▶ Caddy (พอร์ต 443, ใบรับรอง Let's Encrypt ต่ออายุเอง)
                    │  ส่งต่อพร้อม IP จริงของผู้ใช้ (X-Forwarded-For)
                    ▼
                 ระบบจองห้อง (127.0.0.1:3000 เปิดจากภายนอกตรง ๆ ไม่ได้)
                    │
                    ▼
                 /var/lib/bangrak-booking  (ข้อมูล + ไฟล์สำรองรายวัน)
```

> **ก่อนเริ่ม:** ระบบเก็บชื่อและเบอร์โทรของผู้จอง ซึ่งเป็นข้อมูลส่วนบุคคลตาม PDPA
> ควรแจ้งหรือขออนุญาตฝ่ายเทคโนโลยีสารสนเทศของหน่วยงานก่อนนำขึ้นคลาวด์

## 1) เช่าเครื่อง VM

เลือกผู้ให้บริการใดก็ได้ เช่น DigitalOcean, AWS Lightsail, Google Cloud, Azure หรือคลาวด์ภาครัฐ

| รายการ           | ค่าที่แนะนำ                                     |
| ---------------- | ----------------------------------------------- |
| ระบบปฏิบัติการ   | Ubuntu 24.04 LTS (หรือ 22.04)                   |
| ขนาด             | 1 vCPU, RAM 1 GB, ดิสก์ 25 GB (เพียงพอ)         |
| ภูมิภาค          | สิงคโปร์ (ใกล้ไทย ตอบสนองเร็ว)                  |
| พอร์ตที่ต้องเปิด | 22 (SSH), 80, 443 — ที่ไฟร์วอลล์ของผู้ให้บริการ |

แนะนำให้ตั้ง IP ของเครื่องเป็นแบบคงที่ (Static / Reserved IP) และเปิดการสำรองเครื่องอัตโนมัติ (Snapshot/Backup) ของผู้ให้บริการด้วย

## 2) ชื่อโดเมน (แนะนำ)

ตั้ง DNS แบบ **A record** ให้ชื่อที่ต้องการ เช่น `booking.example.go.th` ชี้ไปยัง IP ของเครื่อง VM

ยังไม่มีโดเมน? ข้ามขั้นนี้ได้ สคริปต์จะใช้ชื่อชั่วคราวแบบ `203-0-113-5.sslip.io` ให้ (ได้ HTTPS เหมือนกัน เหมาะสำหรับทดลอง)

## 3) ติดตั้ง (คำสั่งเดียว)

เข้าเครื่องด้วย SSH แล้วนำโค้ดขึ้นเครื่อง เลือกวิธีใดวิธีหนึ่ง

```bash
# ก) ดึงจาก GitHub (repository ส่วนตัวต้องใช้ Personal Access Token แทนรหัสผ่าน)
git clone https://github.com/MiminZeroX/-.git bangrak-booking
cd bangrak-booking

# ข) หรืออัปโหลดไฟล์ zip จากเครื่องตัวเอง แล้วแตกไฟล์
#    scp bangrak-room-booking.zip ubuntu@<IP>:~   (สั่งจากเครื่องตัวเอง)
sudo apt-get install -y unzip && unzip bangrak-room-booking.zip && cd bangrak-room-booking
```

จากนั้นติดตั้ง

```bash
sudo bash deploy/install-vm.sh --domain=booking.example.go.th
```

เสร็จแล้วสคริปต์จะแสดงที่อยู่เว็บและรหัสผ่านผู้ดูแลเริ่มต้น เปิด `https://ชื่อโดเมน/admin.html` แล้วตั้งรหัสผ่านใหม่ได้ทันที

## 4) ระบุ IP ของสำนักงาน (สำคัญ)

เมื่อใช้งานผ่านอินเทอร์เน็ต ทุกเครื่องในสำนักงานจะออกเน็ตด้วย **IP สาธารณะเดียวกัน**
ระบบมีการจำกัดการใช้งานต่อ IP เพื่อกันการโจมตี ถ้าไม่บอกระบบว่า IP นี้คือสำนักงาน
คนหนึ่งใส่รหัสผิดหลายครั้งหรือเปิดหลายหน้าต่าง อาจทำให้ทั้งสำนักงานถูกจำกัดไปด้วย

1. เปิด **หน้าผู้ดูแล › การเชื่อมต่อ** จากเครื่องในสำนักงาน จะเห็น “IP ของคุณที่ระบบเห็น”
2. รันคำสั่งบนเครื่อง VM (หลาย IP คั่นด้วยจุลภาค, ใส่ทั้งเครือข่ายได้ เช่น `203.0.113.0/28`)

```bash
cd ~/bangrak-booking
sudo bash deploy/install-vm.sh --office-ips=203.0.113.10
```

เครือข่ายสำนักงานจะได้เพดานการใช้งานสูงขึ้น 20 เท่า ส่วนการจำกัดต่อบัญชีผู้ใช้และต่อรหัสการจองยังคงเดิม จึงยังกันการเดารหัสผ่านได้

### จำกัดหน้าผู้ดูแลให้เปิดได้เฉพาะในสำนักงาน (ไม่บังคับ)

```bash
sudo bash deploy/install-vm.sh --admin-office-only    # เปิดใช้
sudo bash deploy/install-vm.sh --admin-anywhere       # ยกเลิก
```

ผู้จองทั่วไปยังจองจากที่ไหนก็ได้ตามปกติ

## การดูแลประจำ

| ต้องการ                | คำสั่ง                                                                                  |
| ---------------------- | --------------------------------------------------------------------------------------- |
| ดูสถานะ                | `sudo systemctl status bangrak-booking`                                                 |
| ดูบันทึกการทำงานสด     | `journalctl -u bangrak-booking -f`                                                      |
| เริ่มระบบใหม่          | `sudo systemctl restart bangrak-booking`                                                |
| อัปเดตเป็นเวอร์ชันใหม่ | `cd ~/bangrak-booking && git pull && sudo bash deploy/install-vm.sh` (ข้อมูลเดิมไม่หาย) |
| แก้การตั้งค่า          | แก้ `/etc/bangrak-booking.env` แล้ว `sudo systemctl restart bangrak-booking`            |
| ลืมรหัสผ่านผู้ดูแล     | ดูหัวข้อถัดไป                                                                           |

### ลืมรหัสผ่านผู้ดูแล

```bash
sudo systemctl stop bangrak-booking
sudo -u bangrak node /opt/bangrak-booking/scripts/reset-admin.js --data=/var/lib/bangrak-booking
sudo systemctl start bangrak-booking
```

### ข้อมูลและการสำรอง

- ข้อมูลทั้งหมดอยู่ที่ `/var/lib/bangrak-booking` และระบบสำรองอัตโนมัติวันละครั้งใน `/var/lib/bangrak-booking/backups`
- ไฟล์สำรองรายวันอยู่บนดิสก์เดียวกับระบบ จึงควรเปิด Snapshot ของผู้ให้บริการ และดาวน์โหลดไฟล์สำรองจาก **หน้าผู้ดูแล › สำรอง/กู้คืนข้อมูล** เก็บไว้เป็นระยะ

### ย้ายข้อมูลจากเครื่องในสำนักงานขึ้นคลาวด์

วิธีง่ายที่สุด: ในเครื่องเดิมเปิด **สำรอง/กู้คืนข้อมูล** แล้วนำไฟล์ไปกด **กู้คืน** บนระบบคลาวด์
(บัญชีผู้ดูแลไม่ถูกย้าย ให้สร้างบัญชีใหม่บนคลาวด์)

## แก้ปัญหาเบื้องต้น

| อาการ                                       | สาเหตุ / วิธีแก้                                                                                                    |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| เปิดเว็บไม่ได้ หรือเบราว์เซอร์เตือนใบรับรอง | DNS ยังไม่ชี้มาที่เครื่อง หรือพอร์ต 80/443 ยังไม่เปิดที่ไฟร์วอลล์ของผู้ให้บริการ — ดู `journalctl -u caddy -n 50`   |
| ขึ้น “ชื่อโฮสต์นี้ไม่ได้รับอนุญาต”          | เปิดด้วยชื่ออื่นที่ไม่ใช่โดเมนที่ตั้งไว้ — รันสคริปต์ใหม่ด้วย `--domain=` ที่ถูกต้อง                                |
| ทั้งสำนักงานถูกพักการเข้าสู่ระบบ/การจอง     | ยังไม่ได้ระบุ IP สำนักงาน — ทำตามขั้นที่ 4                                                                          |
| ผู้ดูแลหลุดออกจากระบบบ่อยบนมือถือ           | เครือข่ายมือถือเปลี่ยน IP ระหว่างใช้งาน ระบบจึงให้เข้าสู่ระบบใหม่เพื่อความปลอดภัย (เกิดน้อยเมื่อใช้ Wi-Fi สำนักงาน) |
