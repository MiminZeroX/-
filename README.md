# ระบบจองห้องประชุม · สำนักงานเขตบางรัก

เว็บไซต์ภายในองค์กรสำหรับจอง **ห้องประชุมเล็ก ชั้น 2** และ **ห้องประชุมใหญ่ ชั้น 4**
เปิดใช้ผ่าน Wi-Fi/LAN ของสำนักงานได้ทันที — ไม่ต้องติดตั้งแอป ใช้ได้ทั้งคอมพิวเตอร์ แท็บเล็ต และมือถือ

- ไม่ต้องใช้อินเทอร์เน็ต (ฟอนต์ ไอคอน และ QR Code อยู่ในเครื่องทั้งหมด)
- ไม่ต้องติดตั้งฐานข้อมูลหรือแพ็กเกจเพิ่ม — ต้องการแค่ **Node.js** (รุ่น 18 ขึ้นไป)
- ข้อมูลเก็บเป็นไฟล์ในโฟลเดอร์ `data/` และสำรองอัตโนมัติทุกวัน

---

## เริ่มใช้งาน (ประมาณ 5 นาที)

### 1) ติดตั้ง Node.js บนเครื่องที่จะเป็น “เครื่องแม่ข่าย”

ดาวน์โหลดรุ่น **LTS** จาก <https://nodejs.org> แล้วติดตั้งตามขั้นตอนปกติ
(เครื่องแม่ข่ายคือคอมพิวเตอร์ที่เปิดทิ้งไว้ในสำนักงาน และเชื่อม Wi-Fi/LAN เดียวกับผู้ใช้)

### 2) เปิดระบบ

| ระบบปฏิบัติการ | วิธีเปิด                                           |
| -------------- | -------------------------------------------------- |
| Windows        | ดับเบิลคลิก **`start-windows.bat`**                |
| macOS / Linux  | เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์ `./start.sh` |

หน้าต่างจะแสดงที่อยู่สำหรับเข้าใช้งาน เช่น

```
เปิดจากเครื่องอื่นที่เชื่อม Wi-Fi/LAN เดียวกัน:
  ➜  http://192.168.1.25:3000
หน้าผู้ดูแลระบบ :  http://192.168.1.25:3000/admin
จอแสดงผลหน้าห้อง:  http://192.168.1.25:3000/display
```

> ครั้งแรกที่เปิดบน Windows อาจมีหน้าต่าง **Windows Defender Firewall** ถามสิทธิ์ ให้กด **Allow access** (เลือก Private networks)

### 3) เข้าใช้งาน

- **ผู้ใช้ทั่วไป**: เปิดเบราว์เซอร์ (Chrome, Edge, Safari) แล้วพิมพ์ที่อยู่ที่แสดง เช่น `http://192.168.1.25:3000`
  หรือสแกน QR Code (พิมพ์โปสเตอร์ได้จากหน้าผู้ดูแล › การเชื่อมต่อและ QR)
- **ผู้ดูแลระบบ**: ไปที่ `/admin` ด้วยบัญชีเริ่มต้น `admin` / `admin1234`
  ระบบจะบังคับให้เปลี่ยนรหัสผ่านทันทีในการเข้าสู่ระบบครั้งแรก
- **มือถือ/แท็บเล็ต**: กดเมนู “เพิ่มไปยังหน้าจอหลัก” (Add to Home Screen) จะได้ไอคอนเหมือนแอป

### ตั้งให้เปิดเองอัตโนมัติเมื่อเปิดเครื่อง (Windows)

ดับเบิลคลิก **`windows-autostart.bat`** หนึ่งครั้ง ระบบจะสร้าง shortcut ในโฟลเดอร์ Startup
(ยกเลิกได้โดยลบ `BangRak-Room-Booking.lnk` ใน `shell:startup`)
สคริปต์ `start-windows.bat` จะเริ่มระบบใหม่ให้อัตโนมัติหากหยุดทำงาน

## ความสามารถ

### สำหรับผู้จอง

- **หน้าแรก**: สถานะห้องแบบสด (ว่าง / กำลังใช้งาน / ใกล้เริ่ม) แถบเวลาของวัน นาฬิกา และกำหนดการวันนี้
- **ปฏิทิน**: มุมมองรายวัน รายสัปดาห์ รายเดือน กรองตามห้อง เส้นบอกเวลาปัจจุบัน
  คลิกช่องว่างเพื่อจองทันที ปัดซ้าย/ขวาบนมือถือเพื่อเปลี่ยนวัน
- **จองห้อง 3 ขั้นตอน**: เลือกห้อง → วัน → ช่วงเวลา (แตะเวลาเริ่มและเวลาสิ้นสุด หรือกดปุ่มระยะเวลา/ช่วงเช้า/บ่าย/ทั้งวัน)
  → กรอกรายละเอียด (อุปกรณ์ บริการเสริม จำนวนผู้เข้าร่วมพร้อมแถบความจุห้อง) → ยืนยัน
- **จองซ้ำ** ทุกสัปดาห์หรือทุกวันทำการ พร้อมตรวจสอบห้องว่างล่วงหน้าทุกวัน
- **การจองของฉัน**: แก้ไข ยกเลิก (ยกเลิกเฉพาะครั้งหรือทั้งชุด) เช็คอิน คืนห้องก่อนเวลา
  เพิ่มลงปฏิทินมือถือ (.ics) พิมพ์ใบยืนยันการจองพร้อม QR Code
- ค้นหาการจองจากเครื่องอื่นด้วย **รหัสการจอง + เบอร์โทร**
- ข้อมูลอัปเดตสดทุกหน้าจอทันทีที่มีการจอง/ยกเลิก (ไม่ต้องกดรีเฟรช)

### เอฟเฟกต์และการตอบสนอง

- ทรานซิชันเปลี่ยนหน้า (ทิศทางตามการเลื่อนวัน) ขั้นตอนจองเลื่อนซ้าย/ขวา
- ripple และการยุบตัวเมื่อกดปุ่มทุกปุ่ม, การสั่นเบา ๆ บนมือถือ Android, เสียงคลิก (เปิด/ปิดได้)
- การ์ดลอยขึ้นตามลำดับ (stagger), ตัวเลขนับขึ้น, เครื่องหมายถูกวาดเส้น และพลุกระดาษเมื่อจองสำเร็จ
- bottom sheet ลากลงเพื่อปิดบนมือถือ, สั่นเตือนเมื่อกรอกข้อมูลผิด
- ผู้ดูแลกำหนดระดับเอฟเฟกต์ได้ (เต็มรูปแบบ / เรียบง่าย / ปิด) และผู้ใช้ปรับเองได้ — เคารพการตั้งค่า “ลดการเคลื่อนไหว” ของอุปกรณ์
- ธีมสว่าง/มืด และสีหลัก 8 แบบ

### จอแสดงผลหน้าห้อง (`/display`)

สำหรับแท็บเล็ตติดหน้าห้อง: สถานะห้องตัวใหญ่ การประชุมปัจจุบันพร้อมแถบความคืบหน้า กำหนดการวันนี้
ปุ่มเช็คอิน และ QR Code สำหรับจองด้วยมือถือ — `/display?room=small-2` (ห้องเล็ก), `/display?room=large-4` (ห้องใหญ่), `/display` (ทุกห้อง)

### หน้าผู้ดูแลระบบ (`/admin`)

| เมนู                | รายละเอียด                                                                                                                                                                                                                                                      |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| แดชบอร์ด            | สถิติวันนี้/เดือนนี้ กราฟการจองรายวัน อัตราการใช้ห้อง ช่วงเวลายอดนิยม หน่วยงานที่ใช้มากที่สุด อนุมัติด่วน                                                                                                                                                       |
| รายการจอง           | ค้นหา กรอง อนุมัติ/ไม่อนุมัติ/ยกเลิก ทีละรายการหรือหลายรายการ แก้ไข เพิ่มการจองแทนผู้ใช้ ปิดใช้ห้อง ดูประวัติการแก้ไข ส่งออก CSV (เปิดด้วย Excel ได้)                                                                                                           |
| ห้องประชุม          | เพิ่ม/แก้ไขห้อง ความจุ อุปกรณ์ สี การอนุมัติรายห้อง เปิด/ปิดให้บริการชั่วคราว จัดลำดับ                                                                                                                                                                          |
| หน่วยงานและวันหยุด  | รายชื่อฝ่ายในแบบฟอร์ม และวันหยุดราชการ (เติมวันหยุดวันที่ตายตัวได้ในคลิกเดียว)                                                                                                                                                                                  |
| ตั้งค่าและฟังก์ชัน  | เวลาเปิด-ปิด ช่วงเวลาย่อย ระยะเวลาขั้นต่ำ/สูงสุด เวลาเว้นระหว่างประชุม จองล่วงหน้า เปิด/ปิด: การอนุมัติ การแก้ไข/ยกเลิกโดยผู้จอง การจองซ้ำ การเช็คอินและคืนห้องอัตโนมัติ ความเป็นส่วนตัว ประกาศหน้าแรก ระเบียบการใช้ห้อง โลโก้ ธีม เอฟเฟกต์ โหมดปิดปรับปรุง ฯลฯ |
| ผู้ใช้งานระบบ       | บัญชีผู้ดูแล 2 ระดับ: **ผู้ดูแลระบบ** (ทุกเมนู) และ **เจ้าหน้าที่** (แดชบอร์ด + จัดการ/อนุมัติการจอง)                                                                                                                                                           |
| บันทึกกิจกรรม (Log) | ทุกการจอง แก้ไข อนุมัติ ยกเลิก เข้าสู่ระบบ (รวมครั้งที่ผิดพลาด) และการเปลี่ยนการตั้งค่า พร้อมเวลา ผู้ทำรายการ IP อุปกรณ์ ค้นหา/กรอง/ส่งออก CSV                                                                                                                  |
| สำรอง/กู้คืนข้อมูล  | ดาวน์โหลดไฟล์สำรอง กู้คืนจากไฟล์ ไฟล์สำรองอัตโนมัติรายวัน ข้อมูลสถานะเครื่องแม่ข่าย                                                                                                                                                                             |
| การเชื่อมต่อและ QR  | ที่อยู่ IP ทั้งหมดพร้อม QR Code สำหรับหน้าจอง/จอหน้าห้อง และพิมพ์โปสเตอร์ QR                                                                                                                                                                                    |

ผู้ดูแลจะได้รับการแจ้งเตือน (ข้อความ + เสียง) ทันทีเมื่อมีคำขอจองใหม่ที่รออนุมัติ

## ตัวเลือกการเปิดระบบ

```bash
node server.js --port=8080          # เปลี่ยนพอร์ต (ค่าเริ่มต้น 3000)
node server.js --data=D:\booking    # เปลี่ยนโฟลเดอร์เก็บข้อมูล
```

หรือใช้ตัวแปรแวดล้อม `PORT`, `HOST`, `DATA_DIR`

## ข้อมูลและการสำรอง

| ไฟล์             | เนื้อหา                                                                           |
| ---------------- | --------------------------------------------------------------------------------- |
| `data/db.json`   | การจอง ห้อง การตั้งค่า หน่วยงาน วันหยุด บัญชีผู้ดูแล (รหัสผ่านเข้ารหัสแบบ scrypt) |
| `data/logs.json` | บันทึกกิจกรรม (ลบอัตโนมัติเมื่อเกินระยะเวลาที่ตั้งไว้)                            |
| `data/backups/`  | ไฟล์สำรองอัตโนมัติรายวัน และไฟล์สำรองก่อนการกู้คืน                                |

ย้ายเครื่องแม่ข่าย: คัดลอกทั้งโฟลเดอร์ (รวม `data/`) ไปเครื่องใหม่ หรือใช้เมนูสำรอง/กู้คืนข้อมูล

## แก้ปัญหาเบื้องต้น

| อาการ                         | วิธีแก้                                                                                                                                                                                                                              |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| เครื่องอื่นเปิดไม่ได้         | ตรวจว่าอยู่ Wi-Fi เดียวกัน, อนุญาต Node.js ใน Windows Firewall หรือรันในหน้าต่าง Command Prompt แบบ Administrator: `netsh advfirewall firewall add rule name="BangRak Room Booking" dir=in action=allow protocol=TCP localport=3000` |
| IP เปลี่ยนบ่อย / QR ใช้ไม่ได้ | ตั้ง IP คงที่ให้เครื่องแม่ข่าย หรือทำ DHCP reservation ที่เราเตอร์                                                                                                                                                                   |
| “พอร์ตถูกใช้งานอยู่แล้ว”      | เปิดด้วยพอร์ตอื่น `node server.js --port=3001`                                                                                                                                                                                       |
| ลืมรหัสผ่านผู้ดูแลทุกคน       | ปิดระบบ แล้วรัน `node scripts/reset-admin.js` (ตั้งบัญชี `admin` / `admin1234` ใหม่) จากนั้นเปิดระบบอีกครั้ง                                                                                                                         |
| แท็บเล็ตหน้าห้องดับเอง        | ตั้งค่าหน้าจอแท็บเล็ตให้ไม่ล็อก/ไม่ปิดหน้าจอ และเปิดโหมดเต็มจอ                                                                                                                                                                       |

## ความปลอดภัย

- รหัสผ่านเข้ารหัสด้วย scrypt, session เป็น HttpOnly cookie, ล็อกชั่วคราวเมื่อเดารหัสผิดหลายครั้ง
- ป้องกัน CSRF, XSS (escape ข้อมูลทุกจุด + Content-Security-Policy) และการเข้าถึงไฟล์นอกโฟลเดอร์ `public/`
- ผู้จองจัดการได้เฉพาะการจองของตนเอง (โทเคนลับในอุปกรณ์ หรือรหัสการจอง + เบอร์โทร)
- เบอร์โทรและอีเมลผู้จองไม่แสดงต่อสาธารณะ
- ระบบออกแบบสำหรับเครือข่ายภายใน (HTTP) — **ไม่ควรเปิดให้เข้าถึงจากอินเทอร์เน็ตโดยตรง**

```

public/assets/       CSS, JavaScript (ES modules), ฟอนต์ Anuphan (SIL OFL), ไอคอน
test/                ชุดทดสอบ API
```
